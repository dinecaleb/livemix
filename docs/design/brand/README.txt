DINE brand files

logo/      Symbol and wordmark as SVG (transparent), white (#F5F5F7) and black.
logo/png-transparent/  Same as transparent PNGs, for the website.
app-icon/  Backlit app icon (1d): 1024 PNG, SVG, and a macOS DINE.iconset.
           Before building, rename the "-2x" files to "@2x" (e.g. icon_16x16@2x.png),
           then on a Mac:  iconutil -c icns DINE.iconset
           The 1024 PNG is transparent outside the rounded tile.
social/    1024x1024 avatars, symbol and wordmark, dark and light.

Clear space: one stem width on every side. Minimum: symbol 12px, wordmark 64px wide.
